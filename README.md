One funny line pitching pickled toenails as the worst pizza topping imaginable: briny, crunchy, and somehow the only topping that makes pineapple look like a safe, boring choice.

## Run it

```sh
python3 main.py
```

This writes the entry line to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (defaults to `/output`). The file contains exactly one line, under 200 characters, with no trailing newline.
